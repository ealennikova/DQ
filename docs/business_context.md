# Контекст проекта

## Домен

IoT / wearable data — данные с носимых устройств о физической активности и сне пользователей.

## Бизнес-контекст

Платформа получает ежедневные показатели физической активности и сна пользователей с носимых устройств. Данные используются для формирования пользовательских и аналитических показателей, а также могут передаваться в downstream-системы и аналитические модели.

Качество данных критично для корректного расчёта ежедневных показателей и сопоставимости данных между источниками.

## Основные потребители данных

- аналитические отчёты;
- пользовательские профили активности;
- аналитика сна;
- downstream ML- и аналитические модели.

## Основные риски плохого качества данных

- искажение показателей физической активности;
- некорректный расчёт sleep-метрик;
- двойной учёт данных;
- неверные пользовательские рекомендации;
- недостоверные аналитические выводы;
- снижение качества downstream ML/аналитических моделей.

## Ключевая проблема, выявленная при profiling

Основной выявленный риск связан не с отсутствием данных или недопустимыми значениями, а с интеграцией источников.

После объединения двух источников обнаружено 20 конфликтующих бизнес-ключей `Id + ActivityDay`, затрагивающих 40 записей. Для одного пользователя и одной даты присутствуют несколько записей с различающимися значениями.

Это создаёт риск двойного учёта и формирования противоречивых показателей в аналитике и downstream-процессах.

## Вывод

Для данного домена приоритетным направлением DQ является контроль уникальности и согласованности данных после интеграции источников, а не только проверка структуры и отдельных значений.
